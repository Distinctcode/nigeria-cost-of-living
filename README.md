# Nigeria Cost of Living Dashboard

An interactive data analysis and visualization project exploring the cost of living across Nigerian cities and states.

## Project Goals

- Analyze food prices
- Explore housing and rent costs
- Examine transportation costs
- Compare income and affordability
- Explore inflation trends
- Build an interactive dashboard
- Present findings through clear visualizations
